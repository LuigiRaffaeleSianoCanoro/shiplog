# Adopters

Organizations and open source projects that use Shiplog in a meaningful way (production, serious staging, or public changelog you maintain) may list themselves here.

This is voluntary marketing for you and signal for other users. We do not verify every entry; please be accurate.

## Add your project

Send a **one-line pull request** against `main` that adds an entry under **Listed adopters** using this format:

- **Name:** your project or company name (link optional)
- **Use:** one short phrase (for example "public changelog for our Origin app" or "self-hosted on Vercel Hobby")
- **Contact:** optional GitHub handle for follow-up

Example entry (fictional):

- **Acme Labs** — public changelog at `acme/example` — [@acme-dev](https://github.com/acme-dev)

Keep the description honest and avoid product claims Shiplog cannot substantiate. You may remove or update your line anytime.

Questions about whether Shiplog fits your setup belong in [GitHub Discussions](https://github.com/LuigiRaffaeleSianoCanoro/shiplog/discussions); see [SUPPORT.md](SUPPORT.md).
