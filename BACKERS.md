## How to be listed

1. Sponsor via [GitHub Sponsors](https://github.com/sponsors/LuigiRaffaeleSianoCanoro).
2. Open a pull request that adds your GitHub handle (or organization name) under the tier you use.
3. Keep the entry to one line: name, optional link, optional short note (for example "self-hosts Shiplog").

We do not list amounts or invent endorsements. Remove yourself anytime with a pull request.
